# Facture SN

Outil de facturation pour les freelances au Sénégal : devis et factures en FCFA ou en euros, acomptes, paiements Wave et Orange Money, relances WhatsApp.

- `index.html` : la page de présentation (landing page) avec la liste d'attente.
- `app.html` : le prototype de l'application, avec des données d'exemple.

## État du projet

Ceci est un **prototype de démonstration** :

- les données restent dans le navigateur de chaque visiteur (`localStorage`) ;
- le formulaire de liste d'attente n'enregistre rien ;
- les paiements Wave / Orange Money et l'envoi WhatsApp ne sont pas encore branchés.

## Lancer en local

Ouvrez `index.html` dans un navigateur, ou servez le dossier :

```bash
python -m http.server 8000
```
